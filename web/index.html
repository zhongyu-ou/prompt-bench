运行语义

  • 同一时间只允许一个批次运行；批次内的多个对照组交错派发，共享并发上限。
  • 批次启动时冻结 case、模板、参数、语言路由与渲染请求；之后保存草稿不会改变已启动批次。
  • 停止后不再派发新请求，在途请求会完成并保留结果；刷新页面不会停止批次。
  • 无自动重试。失败会保留原始错误，结果未知（interrupted）不会被当作成功。

共享输入契约

  

    

    
    
    
    
字段填写 type（string / number / integer / boolean / object / array）、required、nullable、description。object 用 fields 定义嵌套字段，array 用 items 定义元素。允许额外 Case 字段。TargetLanguageNameMap 由执行配置注入，不可定义为根输入字段。

    
嵌套示例
{"CurrentText":{"type":"string","required":true,"nullable":false,"description":"已准备好的当前文本"},"Context":{"type":"array","required":false,"nullable":true,"description":"已处理的上下文","items":{"type":"object","required":false,"nullable":false,"description":"上下文项","fields":{"text":{"type":"string","required":true,"nullable":false,"description":"文本"}}}}}

    
共享编辑影响所有引用模板的未来使用；历史保持冻结。不兼容的新格式请复制为另一契约。
